Спорные случаи разметки

Здесь показываются значения, которыми модель НЕ уверена (ниже порога), и значения, которые уже правил человек. Спорное значение можно поставить самому — тогда оно записывается в метаданные документа как ручное: кто, когда и зачем. Ручное значение модель больше не перезаписывает; изменить его может только администратор. Видны только свои документы (администратор видит все).
