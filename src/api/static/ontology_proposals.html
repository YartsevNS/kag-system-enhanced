Очередь предложений онтологии

Требования, извлечённые из нормативных документов. В онтологию (TypeDB) они попадут только после проверки человеком: принять, отклонить, поправить формулировку или отложить как «нужен новый тип схемы». Пока статус «предложено», правил вывода эти факты не касаются — ложных нарушений из непроверенных данных не будет.
