Что это и на что влияет

Модель читает этот текст перед разбором каждого фрагмента: какие типы сущностей существуют (regulator, regulatory_document, structural_element, security_measure, cii_object, threat_source), какие между ними допустимы связи и как выглядит правильный JSON.

Текст фрагмента подставляется вместо {text_chunk} — без этого плейсхолдера модель ничего не увидит. Ниже редактор с проверкой и полной историей версий.
