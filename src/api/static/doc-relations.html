Периодичность

Как это работает

  • При загрузке документа сопоставление запускается сразу — без ожидания периода. Так новый документ сразу получает связи с уже загруженными.
  • Периодический прогон нужен для того, что при загрузке не поймать: старые документы, ссылающиеся на только что загруженный, и документы, чья обработка завершилась позже.
  • Планировщик проверяет каждые 15 минут, но запуск происходит только если с прошлого прогона прошёл заданный период. Поэтому период можно менять здесь, без перезапуска служб.
  • Связь ставится только при точном совпадении идентификатора. Похожие случаи (в тексте «ГОСТ X», в базе «ГОСТ Р X») связью не считаются и попадают в отчёт для человека.
  • Стоимость прогона нулевая: языковая модель не используется, работают правила.
