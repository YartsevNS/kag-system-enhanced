Что означает происхождение для проверки факта

У каждой связи видно: слой (правила — значит найдено детерминированно по тексту; модель — значит извлечено языковой моделью), версия схемы и версия извлекателя (по ним понятно, какими правилами получен факт), фрагмент — на какой кусок текста можно сослаться. Связь без происхождения в граф не пишется: это правило системы, а не пожелание.
