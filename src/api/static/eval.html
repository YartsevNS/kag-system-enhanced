Эталон связей: разметка

Задание. Ниже — 50 требований из документа ФСТЭК «Меры защиты информации в государственных информационных системах» (fstek-2014), извлечённых системой. Для каждого требования проверь две связи и исправь, если система ошиблась:
1) пункт документа, из которого взято требование (например, 3.1, 2.2.4);
2) мера защиты, которой соответствует требование (код меры, например, АВЗ.1, ЗНИ.2).
Поле «что система связала» показывает ответ системы — если он правильный, просто нажми «Подтвердить как есть». Если неправильный — впиши правильные значения и нажми «Сохранить». Если требование не относится ни к одному пункту или мере — оставь поле пустым: пустое поле это тоже ответ («связи нет»).
Зачем: твои ответы — эталон, по которому измеряется точность извлечения. После разметки любую правку промпта можно проверить числом (сколько из 50 связей совпало), а не ощущением.
