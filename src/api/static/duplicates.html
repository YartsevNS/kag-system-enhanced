Возможные дубли

Сюда попадают документы, которые похожи на уже загруженные, но пришли другим файлом (другой скан, водяной знак, копия с другого источника) — то есть с другим хешем. Точное совпадение байтов отсекается при загрузке автоматически и здесь не показывается. Ничего не происходит без решения человека: «Новая редакция» — связать как версию (прежняя уйдёт из поиска после обработки), «Копия» — дописать источник к существующему и убрать лишнюю запись, «Другой документ» — закрыть вопрос без изменений.
