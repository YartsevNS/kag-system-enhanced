Задание извлечения связей

Этот текст управляет тем, какие связи попадут в граф знаний. Здесь он целиком, с последствиями правки.

Что это такое

По каждому фрагменту документа модель извлекает сущности и связи между ними. Задание ниже — это то, что модель читает перед каждым разбором: какие типы связей существуют, между какими типами сущностей они допустимы и примеры правильного и неправильного выбора.

После ответа модели каждая связь ещё раз проверяется словарём: тип должен быть из списка, а пара «тип источника → тип цели» — разрешённой. Что не прошло проверку — в граф не пишется, но видно в журнале. То есть задание и словарь работают вместе: словарь — это закон, задание — это инструкция для того, кто его исполняет.
