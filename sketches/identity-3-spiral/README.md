## Вариант: Спираль

### Позиция
Концентрические дуги сходятся к точке; техническая монопись, «позвоночник» меню.

### Ключевые решения
- Монопись в витрине, вертикальная линия-позвоночник, точка-акцент на активном пункте
- Шрифты: Cascadia Code/Consolas + system-ui
- Цвета: светлая нейтральная основа, акцент #08A652 (подменяется брендбуком через переменные)
- Значки: эмодзи убраны полностью, вместо них — типографика

### Компромиссы
- Сильная сторона: Сильный образ «прибора», точные цифры, ноль внешних зависимостей
- Слабая сторона: Монопись утомляет в длинных текстах — только витрина, не тело

### Кому подходит
Офисным сотрудникам, работающим в системе весь день; монограмма различает продукт, не мешая работе.
