## Вариант: Три кольца

### Позиция
Строгая капитель и нумерация вместо значков; монограмма — трилистник из трёх колец, точка в центре = пользователь.

### Ключевые решения
- Капс с широким трекингом, номера пунктов 01..11, акцентная черта слева
- Шрифты: system-ui
- Цвета: светлая нейтральная основа, акцент #08A652 (подменяется брендбуком через переменные)
- Значки: эмодзи убраны полностью, вместо них — типографика

### Компромиссы
- Сильная сторона: Максимально предсказуемо для офиса, легко ложится на любой брендбук
- Слабая сторона: Менее «изотерично» — мистика только в монограмме

### Кому подходит
Офисным сотрудникам, работающим в системе весь день; монограмма различает продукт, не мешая работе.
