## Вариант: Плетение

### Позиция
Засечная (serif) витрина: буквы R, K, C сплетаются в узел, ромб в месте плетения — пользователь.

### Ключевые решения
- Georgia в заголовках и подписях групп, ромбы вместо значков, тонкие линейки
- Шрифты: Georgia + system-ui
- Цвета: светлая нейтральная основа, акцент #08A652 (подменяется брендбуком через переменные)
- Значки: эмодзи убраны полностью, вместо них — типографика

### Компромиссы
- Сильная сторона: Издательский вес, «дорогой» вид, изотерика читается как традиция
- Слабая сторона: Serif-шрифт надо вшить в образ (OFL), иначе на Linux подмена

### Кому подходит
Офисным сотрудникам, работающим в системе весь день; монограмма различает продукт, не мешая работе.
