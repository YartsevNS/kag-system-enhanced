# DRAGON (Dynamic RAG Benchmark On News) — публичная часть

Источник: Сбер / AI Forever, `ai-forever/hist-rag-bench-public-*` на Hugging Face; репозиторий
и статья — `RussianNLP/DRAGON`, arXiv:2507.05713.
Лицензия: **Apache-2.0** (коммерческое использование разрешено, ограничений нет).

## Что лежит здесь

| Файл | Содержимое |
|---|---|
| `hist-rag-bench-public-questions.parquet` | 600 вопросов на русском (`id`, `question`) |
| `hist-rag-bench-public-texts.parquet` | 542 текста новостей (`id`, `text`) — корпус для поиска |

Поля: `id` связывает вопрос и текст в приватной части набора (там же лежат ответы-эталоны).

## Чем полезно нам

1. **Нагрузочный и языковой прогон поиска:** 600 запросов на русском против 542 документов —
   измерить задержку и стабильность без ожидания появления большого корпуса заказчика.
2. **Проверка гибридного поиска и фильтров** на постороннем материале (новости): если ломается
   на новостях — ломается и на документах.
3. **Основа для набора с эталонами.** Правильные ответы лежат в приватной части
   (`hist-rag-bench-private-qa`), доступ к ней может требовать согласия — проверить отдельно.
   Без эталонов recall@k не считается: сейчас набор годится для задержки и связности, не для recall.

## Как читать

```python
import pyarrow.parquet as pq
q = pq.read_table("eval/dragon/hist-rag-bench-public-questions.parquet").to_pylist()
t = pq.read_table("eval/dragon/hist-rag-bench-public-texts.parquet").to_pylist()
```
