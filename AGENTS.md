# Правила работы в этом репозитории

Короткая памятка для агента и людей. Читается автоматически в начале сессии.

## Где что лежит

| Вопрос | Файл |
|---|---|
| С чего начать, что за проект | `docs/PROJECT-MAP.md` |
| Как устроена система сейчас | `docs/ARCHITECTURE-JOURNAL.md` |
| Что делаем в этот раз | `docs/changes/<дата>-<название>/` |
| Почему устроено так | `project_typedb/adr/NNN-*.md` |
| Что отложено | `docs/tech-debt.md` |
| Выкат, откат, состав серверов | `docs/guides/deploy.md` |

## Правила

1. **Крупная работа — сначала папка изменения.** Если работа дольше дня или затрагивает схему
   БД, контракт API, состав контейнеров — `python scripts/new_change.py "название"`, заполнить
   `proposal.md` и `specs.md`, утвердить, потом код. Мелкая правка — только запись в
   `docs/ARCHITECTURE-JOURNAL.md`.
2. **После выката — запись в журнал.** Одна строка: дата, что изменилось, чем проверено.
3. **ADR перед кодом.** Смена архитектурного решения фиксируется в `project_typedb/adr/` до
   реализации, а не после.
4. **Наполнение онтологии — только через flow** (обработка документа или принятие предложения).
   Ручные скрипты и фикстуры в рабочую базу TypeDB не пишутся.
5. **Терминология.** Сервер — по IP (`192.168.50.18`), контейнер — по имени (`kag-api`),
   образ — `repo:tag`, база — по имени (`cybersecurity_ontology_v2`). Не использовать «стенд»,
   «пилот», «мусорный» без точного указания объекта.
6. **Цифра без объекта — брак.** Не «237 сущностей», а «237 объектов в
   `cybersecurity_ontology_v2`: 166 `structural_element`, 37 `security_measure`, …».
7. **Не трогать** ветку `PREPROD` и базу `cybersecurity_ontology` — это путь отката.
8. **Промпт извлечения сущностей — авторский** (`src/api/services/ontology_prompts.py`).
   Правки предлагать, не применять молча.

## Проверка изменений

```bash
python -m py_compile <файлы>          # синтаксис
pytest                                 # тесты (в контейнере kag-api)
docker ps --format '{{.Names}}'        # контейнеры на 192.168.50.18
curl localhost:8000/api/v1/health      # 200 на сервере
```
