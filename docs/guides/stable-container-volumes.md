# Контейнер — постоянная величина, настройки — в volume

Требование владельца (07.11.2026): «контейнер остаётся постоянной величиной, но у него есть
volume, где держатся все настройки и переменные; внося изменения в переменные, достаточно
перезапустить контейнер». Правило для всех будущих работ.

## Принцип

Код и версия — в образе (`kre44et/kag-api:<tag>`). Всё, что меняется при настройке
и может меняться без пересборки, живёт в volume или в базе настроек, а не в слое образа.

Проверка перед любой правкой: «это изменится без `docker build`?» Если нет — это нарушение
правила, нужно перенести в настройку.

## Где что лежит сейчас

| Что | Где | Меняется перезапуском? |
|---|---|---|
| Настройки моделей, провайдеров, промпты | Postgres, `system_configs` (config_store) + `ontology_prompts` | да (перечитать/перезапуск) |
| Параллельность извлечения | `system_configs: system/extraction.parallel` | да (со следующего прогона) |
| Сбор статистики этапов | `system_configs: system/process_logs.collect` | да |
| Словарь терминов, авто-решения, очереди | Postgres (`entity_aliases`, `ontology_auto_decisions`) | да |
| Документы, чанки, метаданные | Postgres (volume `kag_db_data`) | нет (данные) |
| Векторы | Qdrant (bind `./data/qdrant`) | нет (данные) |
| Оригиналы документов | S3 (silo) и `./data/uploads` | нет (данные) |
| Онтология | TypeDB (volume) | нет (данные) |
| HTML/CSS/JS интерфейса | внутри образа `src/api/static` | **нет — только пересборка** (техдолг п.9) |
| Модели OCR/эмбеддингов (веса) | внутри образа (офлайн-контур) | нет (поставляются с образом) |

## Что осталось нарушением и как исправить (по техдолгу)

1. **Статика интерфейса (п.9).** Держать `src/api/static` в папке `site/` на хосте и монтировать
   в `/app/src/api/static:ro` — правка вёрстки без пересборки и без рестарта api.
2. **Схема и функции онтологии.** Должны применяться через админку (`/ontology`, `define`)
   и храниться в базе версий, а не только в файле образа. Файл — эталон поставки, база — истина.
3. **Каталоги данных в compose.** Никогда не переопределять пути, вшитые в образ
   (`HF_HOME`, `PLAYWRIGHT_BROWSERS_PATH`) — иначе офлайн-веса «пропадают».

## Как проверять после выката

    docker inspect <контейнер> --format '{{.Config.Image}}'   # версия из образа
    docker exec kag-api printenv | grep -E 'TYPEDB_|KAG_DB'    # переменные окружения
    # настройка изменилась без пересборки:
    #   поменять поле в админке → перезапустить api → проверить поведение
