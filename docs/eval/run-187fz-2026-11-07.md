## Найденный дефект: источник отправлял документ в новости

Первая попытка загрузки (с теми же метаданными, но без `collection`) дала:

    collection = news
    kag_news      48 фрагментов
    kag_documents 1 точка (только карточка)
    поиск по корпусу документ не видит

Причина: `collection_for_source()` считает новостью ЛЮБОЙ документ с `source_url`/`source_name`
(так загружает web_monitor). Отдельного способа сказать «это документ корпуса, но с источником»
не было — то есть требование «сохраняй источник в метаданных» автоматически выбрасывало нормативный
акт из корпуса.

Исправлено: у загрузки появилось поле `collection` (`documents` | `news`); значение пишется в БД
словом, потому что пустая строка снова уходит в эвристику по источнику. Тесты:
`tests/test_upload_collection_route.py` (5 проверок).

## Ограничение, не исправленное: граф без сущностей

Для документа созданы разделы и чанки, но извлечение сущностей графа не выполнялось: 18 узлов
типа `clause` против 32 381 сущности в базе у 171 документа. Для двух других документов, обработанных
в этот же день: `8ef6b9c4` — 3 узла (`standard`), `36fdd4d3` — 0 узлов. Причина — `system/graph.skip=true`
(«граф строим по кнопке»): `rebuild_graph_task` строит разделы и чанки, но не извлекает сущности.
Записано в `docs/tech-debt.md`, п. 15.
