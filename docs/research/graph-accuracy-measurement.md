# Точность извлечения графа: первый честный замер (10.10.2026)

До сих пор точность графа не измерялась ни разу: мы знали, сколько связей построено, но не знали,
сколько из них верны. Этот замер закрывает пробел. Судит **отдельная модель** (JEV через Polza) —
своим судьёй быть нельзя; вопросы задаются закрытыми, с вероятностями.

## Как мерили

Приборы: `scripts/bakeoff/dump_extraction_sample.py` (снимает на стенде «текст → что мы извлекли»)
и `scripts/bakeoff/jev_graph_accuracy.py` (судит на ноутбуке; ключ только из окружения).

По каждой связи задавались два вопроса:
* **«следует ли связь из текста»** — тип `noul`, то есть вероятность «да» (а не мнение словами);
* **«какой тип связи точнее описывает отношение»** — тип `choice` с вариантами ИЗ НАШЕЙ онтологии
  (13 типов + «тип не определён»), то есть судья выбирает в наших рамках, а не придумывает своё.

## Результат (12 фрагментов, 54 связи)

| Показатель | Значение |
|---|---|
| Связь действительно следует из текста | **88,9%** (48 из 54) |
| Тип связи совпал с нашим | **48,1%** (26 из 54) |
| Расход на замер | 0,605 ₽ (≈0,05 ₽ на связь) |

То есть **связи мы находим, а тип определяем через раз**.

Где судья поставил другой тип (наши данные → его выбор):

| Наш тип | Тип судьи | Сколько |
|---|---|---|
| BELONGS_TO | RELATED_TO (тип не определён) | 5 |
| BELONGS_TO | APPLIES_TO (распространяется на) | 4 |
| DATED | APPLIES_TO | 3 |
| RELATED_TO | LOCATED_AT | 3 |
| BELONGS_TO | DEFINES (определяет) | 2 |
| LOCATED_AT | RELATED_TO | 2 |
| LOCATED_AT | PART_OF | 2 |
| прочие (по 1) | ISSUED_BY, REQUIRES, PART_OF, AMOUNT→RELATED_TO | 6 |

## Выводы (что делаем)

1. **Не выдавать догадку за факт.** `BELONGS_TO` больше НЕ раскладывается в `PART_OF` (это была
   выдуманная точность: в половине случаев судья такую связь типом не считает). Теперь честно
   `RELATED_TO` — «тип не определён», а точный тип назначается отдельным проходом.
2. **Тип связи — главный рычаг точности.** Связи в тексте есть (89%), значит проблема не в поиске
   фактов, а в их разметке. Дешёвый путь: проход JEV по вероятностям ТОЛЬКО по неопределённым
   связям (RELATED_TO и спорные) — судья выбирает из нашего же списка. Ориентир по цене: 0,05 ₽
   на связь; если неопределённых связей в корпусе около 10 тысяч, проход стоит порядка 500 ₽ и
   даёт заполненный тип там, где сейчас пусто.
3. **Онтология пока не покрывает часть формулировок.** Судья чаще всего предлагает `APPLIES_TO` —
   значит либо наши допустимые пары для него узки, либо модель не выбирает его зря. Проверить на
   следующем замере после расширения словаря.
4. **Мерить надо регулярно.** Замер стоит копейки и превращает спор о качестве в цифру: теперь
   любое изменение промпта или онтологии можно проверить на тех же 12 фрагментах за 0,6 ₽.

## Ограничения замера (честно)

* 12 фрагментов и 54 связи — это первая оценка, а не приговор: для устойчивых выводов нужно
  50–100 фрагментов и разные виды документов (нормативные, таблицы, сканы).
* Судья — тоже модель: она может ошибаться. Для калибровки нужна небольшая ручная проверка
  (10–15 связей, где владелец или я точно знаем ответ) — тогда видно, насколько судья строг.
* Расхождения по типу не всегда означают ошибку: `DATED → APPLIES_TO` может быть спорным случаем,
  а не браком.
